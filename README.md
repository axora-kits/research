# Axora research

Public shortlist of open-source projects we study for beginner-friendly kits (homes, makers, students).  
Brand: **Axora** · Contact: **axora.kits@gmail.com**

We do **not** own these projects. We credit upstream authors and check licenses before any commercial kit.

## Priority shortlist

| Priority | Project | Why it matters | Kit idea |
|---------:|---------|----------------|----------|
| 1 | [ESPTimeCast](https://github.com/mfactory-osaka/ESPTimeCast) | Weather + clock, browser flash | Axora Forecast |
| 2 | [ESPHome](https://github.com/esphome/esphome) | Easiest DIY sensors for Home Assistant | Axora Read / Auto |
| 3 | [esp32-weather-epd](https://github.com/lmarzen/esp32-weather-epd) | Popular weather display | Axora Weather |
| 4 | [WLED](https://github.com/wled/WLED) | LED strips | Axora Glow |
| 5 | [Tasmota](https://github.com/arendst/Tasmota) | Automation firmware | Axora Auto |
| 6 | [Home Assistant](https://github.com/home-assistant/core) | Ecosystem hub | Integration target |
